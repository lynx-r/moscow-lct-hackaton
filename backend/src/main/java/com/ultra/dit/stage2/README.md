# Stage 2: Геометрическая трассировка и поиск коллизий

Пакет инкапсулирует логику автоматической пространственной кластеризации, локализации расчетных окон, скелетизации свободного пространства и генерации вариантов трассировки тепловой сети.

## Структура пакета

```bash
com.ultra.dit.stage2/
  ├── NetworkRoutingService.java       # Главный оркестратор (Фасад) конвейера трассировки
  ├── OksClusteringService.java        # Шаг 2.0: Пространственная кластеризация ОКС (d <= 100м)
  ├── LocalBoundingBoxService.java     # Шаг 2.1: Локализация данных в окне поиска (+500м)
  ├── CollisionDetectionService.java   # Шаг 2.4: Валидация 2D-буферов труб (2.0м) и коллизий
  ├── model/                           # Доменные модели и неизменяемые DTO этапа
  │   ├── OksObject.java               # Перспективный ОКС с точкой подключения и расходом
  │   ├── VirtualNode.java             # Узел графа, учитывающий координаты и вектор захода
  │   ├── NodeType.java                # Типы опорных и целевых узлов каркаса
  │   ├── Vector2D.java                # Математический вектор для расчета углов излома
  │   └── RoutingResult.java           # Контейнер итоговой топологии варианта сети
  └── graph/                           # Движок вычислительной геометрии и теории графов 
      ├── DirectedRoadmapBuilder.java   # Шаг 2.2: Скелетизация (Вороной) и сборка ориентированного графа
      ├── RouteWeightCalculator.java    # Шаг 2.3: Матрица штрафов за углы поворота в весах ребер
      └── NetworkTopologyGenerator.java # Шаг 2.5: Алгоритм Йена (K кратчайших путей) и контроль валентности
```

## Ключевые особенности реализации

1. **Масштабируемость (Защита от OOM)**: Локализация расчетной области через `LocalBoundingBoxService` 
вырезает микро-выборку объектов из глобальных R-Tree (`STRtree`). Это минимизирует аллокации памяти в пределах лимита **16 ГБ RAM**.
2. **Virtual Layer**: Вершины `VirtualNode` дублируются под разные векторы захода. Это позволяет 
JGrapht штрафовать изломы трассы на стыках ребер.
3. **Защита от самоблокирования**: Финальный прямой участок трубы, заходящий 
в `connectionPoint` здания, освобождается от проверки отступа к собственному полигону этого ОКС.
