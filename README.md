# Хакатон Лидеры Цифровой Трансформации 2026

## Задача

Сервис моделирования трассировки тепловых сетей для технологического присоединения новых зданий

### Актуальность

В настоящий момент процесс подключения новых зданий к инженерной инфраструктуре города может вызывать сложности, связанные с расчетами и формированием трассировки, информацией о расположении существующих инженерных коммуникаций и порой длительными согласованиями.

### Описание задачи

Разработайте сервис, который на основе обработки массива геоданных существующих и запланированных объектов (зданий, инженерной инфраструктуры, автомобильных дорог и т.д.) предложит варианты оптимальных трассировок для подключения перспективного здания к тепловым сетям.

### Ресурсы

Массив геоданных, низкополигональные модели зданий.

### Описание итогового продукта

Программный продукт (сервис).
