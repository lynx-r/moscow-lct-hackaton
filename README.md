## 🎯 Актуальность

В настоящий момент процесс подключения новых зданий к инженерной инфраструктуре города может вызывать сложности, связанные с:

- расчётами и формированием трассировки;
- информацией о расположении существующих инженерных коммуникаций;
- порой длительными согласованиями.

&nbsp;

## 🧩 Описание задачи

Разработайте сервис, который на основе обработки массива геоданных существующих и запланированных объектов (зданий, инженерной инфраструктуры, автомобильных дорог и т.д.) предложит варианты **оптимальных трассировок** для подключения перспективного здания к тепловым сетям.

&nbsp;

## 📦 Ресурсы

- Массив геоданных;
- Низкополигональные модели зданий.

&nbsp;

## 🚀 Описание итогового продукта

Программный продукт (сервис), позволяющий автоматизировать расчёт и формирование трассировки тепловых сетей для технологического присоединения новых зданий.

## Интеграция расчётного ядра Python/C++

Текущее ядро, правила, исходные документы и тесты находятся в [`solver/`](solver/README.md).
Java API `/routing/process` и `/routing/process-json` вызывает внутренний сервис
расчёта. Инструкция по запуску и проверке: [solver/README.md](solver/README.md).
Изолированный локальный запуск без БД: `docker-compose -f docker/docker-compose-solver.yml up -d --build`.
